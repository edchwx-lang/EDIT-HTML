# Design Selection

Mode chooses what the report prioritizes. Design direction chooses how the same content is organized and operated. Theme chooses semantic colors only.

Without a reference, three directions are a layout/interaction decision aid. Hold mode, real content slices, coverage, and `previewThemeId` constant. Vary hierarchy, density, typography, component composition, table/chart treatment, master-detail behavior, and responsive rhythm.

With a reference, do not invent three unrelated styles. Produce one coherent direction and demonstrate three representative scenes: hero/overview, data/table, and master-detail/evidence. The reference may influence the candidate; it does not become a permanent built-in template.

The selected showcase and final report must use the same candidate grammar and default theme. Only an explicit theme change in the visible editor may diverge from `previewThemeId`, and that change invalidates review confirmation.
