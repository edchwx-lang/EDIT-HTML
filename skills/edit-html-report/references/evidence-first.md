# Evidence-first Mode

Evidence-first prioritizes deep judgment and traceable support. Charts remain valid evidence carriers, but density is subordinate to the argument.

## Priority chain

`core judgment → evidence → explanation → qualification/counterexample → source`

Evidence may be a source quotation, logic chain, number, original table, original figure, case, footnote, or citation. Preserve original figures, tables, qualifications, and source context whenever they carry meaning. Use continuous reading width and expandable evidence blocks; do not turn the report into a sparse presentation deck.

Every principal judgment must resolve to one or more source IDs. A chart is permitted only when it strengthens a judgment and must use the same provenance and accessibility rules as data-first. Evidence-first has no minimum KPI or chart count.
