# Edit HTML Report V5.2 Editor Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Connect every V5 editor control to the HTML-backed artifact contract and remove design/theme confirmation from saving and publishing.

**Architecture:** Extend V5 instrumentation with deterministic descendant edit identities and route editor actions through HTML or model adapters according to artifact mode. Keep legacy model editing compatible while making V5 saving depend only on artifact state and publishing depend on a clean saved version.

**Tech Stack:** Node.js 20+, native test runner, parse5, Playwright.

## Global Constraints

- Package and pipeline version are `5.2.0`.
- Huashu DOM structure, classes, geometry, and content remain unchanged by instrumentation.
- V5 uses HTML patches; V4 model-backed projects retain model patches.
- The visible editor contains no design/theme confirmation control or save gate.
